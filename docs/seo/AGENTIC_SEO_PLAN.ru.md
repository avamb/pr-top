**Подготовлено:** 06.07.2026. Продолжение [SEO_PLAN.md](SEO_PLAN.md) (фазы 1–3 в проде: пререндер, локальные URL, hreflang, sitemap, JSON-LD).
**Репозиторий:** `C:\Projects\dev-psy-bot`, ветка `dev` (Dokploy деплоит прод из `prod`; промоушен — fast-forward merge `dev` → `prod`).
**Состав:** три программы, работающие в основном на агентах:
- **A. GEO (Generative Engine Optimization)** — чтобы PR-TOP цитировали и рекомендовали ChatGPT, Perplexity, Claude, Copilot, Google AI Overviews.
- **B. SEO-машина на агентах** — регулярные SEO-операции выполняют агенты по расписанию / AutoForge, а не люди.
- **C. Конкурентная контент-программа** — забрать сравнительные запросы и запросы «лучший X» у названных конкурентов.

Логика: терапевты всё чаще спрашивают ИИ-ассистентов («best AI note-taker for therapists», «как психологу вести заметки с ИИ»), а не Google. Ответы ИИ выигрываются за счёт: доступного без JS контента (сделано), «answer-shaped» страниц, покрытия сравнительных запросов, присутствия бренда на источниках, которым доверяют LLM (G2, Reddit, каталоги), и свежести. Классическое SEO (фазы 1–3) — фундамент; этот план — слой роста.

## Программа A — GEO: видимость в ответах ИИ

### A1. Открыть дверь ИИ-краулерам (30 мин, задача для AutoForge)
Дополнить `src/frontend/public/robots.txt` явными блоками разрешений для ИИ-краулеров (при сохранении текущих Disallow-правил): `GPTBot`, `OAI-SearchBot`, `ClaudeBot`, `Claude-SearchBot`, `PerplexityBot`, `Google-Extended`, `Bingbot` — каждому `Allow: /` плюс тот же список Disallow для приватных разделов.
**Зафиксированное решение:** мы ХОТИМ попадать в обучение и ответы моделей — продукту выгодно быть известным моделям. Проверить, что WAF/Traefik не режет эти user-agent'ы (посмотреть логи доступа через неделю).
**Приёмка:** `curl https://pr-top.com/robots.txt` содержит блоки GPTBot/ClaudeBot/PerplexityBot.

### A2. llms.txt + llms-full.txt на каждой сборке (полдня, AutoForge)
Добавить в сборку (`src/frontend/scripts/`) скрипт `generate-llms.mjs`:
- `dist/llms.txt` — курируемый Markdown-индекс по конвенции llmstxt.org: абзац о продукте, затем сгруппированные ссылки (Продукт, Безопасность, Цены, Сравнения, Языки) с однострочными описаниями.
- `dist/llms-full.txt` — склеенный плоский текст всех публичных маркетинговых страниц (извлечение из пререндеренного HTML).
- Перегенерируется при каждой сборке из общего манифеста маршрутов → никогда не устаревает.
**Приёмка:** оба файла отдаются как `text/plain`; llms.txt перечисляет каждую публичную страницу; содержимое совпадает с живыми страницами.

### A3. Стандарт «answer-shaped» контента (правило для всех будущих страниц)
Каждая маркетинговая/контентная страница обязана содержать: прямой ответ на главный вопрос страницы в 40–60 слов в первом блоке (LLM цитируют его дословно); сканируемую иерархию H2/H3; блок статистики с источниками; секцию FAQ со schema FAQPage; сравнительную таблицу, где уместно. Уверенный утвердительный тон — расплывчатый текст ИИ-движки пропускают.
**Где закрепляется:** чеклист в `docs/seo/CONTENT_RULES.md`, на него ссылается каждый промпт контент-агента (см. B2).

### A4. Страницы сравнений и альтернатив — самый доходный GEO-актив (цели — в программе C)
LLM, отвечая на «best X» и «X vs Y», непропорционально часто тянут данные со страниц, где сравнение уже сформулировано. Конкуренты (Mentalyc, Twofold) агрессивно публикуют такие страницы; у PR-TOP их ноль. Строим `/compare/<конкурент>` и `/alternatives/<конкурент>` (сначала EN, затем RU/UK/ES) — детали в C2.

### A5. Присутствие бренда на источниках, которым доверяют LLM (человек + помощь агента, постоянно)
LLM цитируют агрегаторы чаще, чем сайты вендоров. Приоритеты:
1. **Листинги G2 + Capterra** с ≥5 настоящими отзывами (попросить пилотных пользователей) — эти две площадки цитируются почти в каждом ИИ-ответе «best therapy software».
2. **Запуск на Product Hunt** (уже в SEO_PLAN, фаза 7) — страницы PH активно сканируются LLM.
3. **Reddit**: треды r/therapists про ИИ-нотейкеры — топовый источник LLM. Только честное участие; один честный пост «мы это построили» по правилам сабреддита.
4. Листинг **AlternativeTo** (его страницы «alternatives to Upheal/Mentalyc» напрямую питают ответы ИИ).
5. RU: статья основателя на Habr/vc.ru; профиль на B17.ru — русскоязычное пространство ИИ-ответов по «ИИ для психолога» почти пустое → преимущество первопроходца.
**Помощь агента:** агент готовит тексты листингов, письма с просьбой об отзыве и комплект для запуска на PH; человек нажимает «отправить».

### A6. Измерение ИИ-видимости (агент, еженедельно)
- Umami: сегмент рефереров `chatgpt.com`, `perplexity.ai`, `copilot.microsoft.com`, `gemini.google.com` (+ utm с PH/G2). Базовая линия сегодня: ~0.
- Отчёт **AI Performance (BETA)** в Bing Webmaster — фиксировать еженедельно.
- Панель промпт-проб: агент по расписанию ежемесячно задаёт фиксированный набор из ~20 вопросов (EN+RU: «best AI assistant for therapists with Telegram», «телеграм-бот для психолога с дневником клиента», «Upheal alternatives»…) моделям с веб-поиском и записывает, упомянут/процитирован ли PR-TOP, в `docs/seo/reports/ai-visibility-ГГГГ-ММ.md`.
**KPI:** упоминание PR-TOP в ≥3 из 20 EN-промптов за 4 месяца, в ≥8 из 20 RU-промптов (конкуренция слабая).

## Программа B — SEO-машина на агентах

Регулярные операции, каждая выполнима агентом по расписанию (cron/routine Claude Code) или фичей AutoForge. Все отчёты ложатся в `docs/seo/reports/` и коммитятся в `dev`.

### B1. Еженедельный SEO-монитор (агент, 30 мин/нед, только чтение)
Скрипт + агент: забирает данные GSC Search Analytics API (разовая настройка OAuth/сервис-аккаунта — `[ЧЕЛОВЕК]`) и API Яндекс.Вебмастера; прогоняет live-проверки приёмки из SEO_PLAN фазы 1; сверяет счётчики `site:pr-top.com`. Выход: `reports/seo-weekly-ГГГГ-НН.md` — страницы в индексе, показы/клики, топ-запросы, новые ошибки покрытия, упавшие проверки. Регрессии автоматически оформляет как баг-фичи AutoForge.

### B2. Контентный конвейер (агент производит, человек утверждает, ~2–4 страницы/мес)
Цикл на страницу: (1) выбор целевого запроса из данных GSC «показы без страницы» + пробелы из C1 → (2) агент пишет бриф (интент, структура, страницы конкурентов, внутренние ссылки) → (3) агент делает черновик страницы как React-маршрут на всех 4 языках по правилам A3 → (4) **вычитка человеком** (тон в этой нише критичен) → (5) merge → sitemap/пререндер обновляются сами → (6) пинг IndexNow (B3) + ручной запрос в GSC `[ЧЕЛОВЕК, 1 мин]`.
Страницы наследуют паттерн манифеста маршрутов (F2), поэтому sitemap/пререндер/llms.txt подхватывают их без дополнительной работы.

### B3. IndexNow при деплое (2 ч, AutoForge)
Сгенерировать ключ IndexNow в `src/frontend/public/`, добавить `scripts/indexnow-ping.mjs`, который отправляет изменённые URL (дифф sitemap против прошлой сборки или весь список — 28+ URL это нормально) на `api.indexnow.org` (покрывает Bing + Яндекс). Подключить как post-deploy шаг или запуск агентом по вебхуку Dokploy.
**Приёмка:** файл ключа отдаётся; пинг возвращает 200; в разделе IndexNow в Bing Webmaster видны отправки.

### B4. Наблюдение за конкурентами (агент, ежемесячно)
Агент обходит страницы цен/фич/блогов конкурентов (Upheal, Mentalyc, Twofold, Heidi, Supanote, Freed, Eleos + новые игроки из поиска), сравнивает со снапшотом прошлого месяца в `docs/seo/competitors/` и выдаёт: изменения цен, новые фичи, новый сравнительный контент против нас и требуемые правки наших страниц `/compare/*` (которые уходят в конвейер B2).

### B5. Технический SEO-регресс в CI (уже готов на 80%)
Расширить `_t_seo_i18n_audit.js`: проверять блоки ИИ-краулеров в robots.txt, существование и полноту llms.txt, совпадение числа URL в sitemap с манифестом, description ≤160 символов на каждой странице (закрывает придирку Bing оптом), ровно один H1, парсинг JSON-LD. Запускать в каждой сессии AutoForge по собранному `dist/`.

### B6. Сбор отзывов и упоминаний (агент помогает, постоянно)
Агент ведёт `docs/seo/outreach/`: список проспектов (подкасты, рассылки для терапевтов, обучающие институты RU/UA/ES), черновики персонализированных питчей, трекер. Отправляет человек со своей почты (доставляемость + аутентичность). Цель: 4 питча/неделю, ≥10 ссылающихся доменов к 3-му месяцу.

### KPI (6 месяцев)
- Ответы ИИ: PR-TOP цитируется в ≥3/20 EN и ≥8/20 RU промптов панели (A6).
- Органика: сравнительные страницы дают ≥30% небрендовых органических кликов; ≥5 позиций на первой странице Google в RU-кластере.
